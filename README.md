# 🛒 SHOP

SHOP is a web-based shopping platform built with **Flask**, **HTML**, **CSS**, **Bootstrap**, and **Jinja**.

The project allows users to browse products, buy and sell products, and manage items in their basket.

## ✨ Features

- 🏠 Home page
- 📦 View available products
- 🛍️ Buy products
- 💰 Sell products
- 🛒 Add products to a basket
- 📋 View basket
- 🔐 User registration and login
- 🔑 Password confirmation during registration
- 🎨 Responsive design using Bootstrap
- ⭐ Font Awesome icons

## 🛠️ Technologies

- Python
- Flask
- Jinja2
- HTML5
- CSS3
- Bootstrap
- Font Awesome
- SQLite
